# 1주차: 16진 카운터 회로

> 블로그: [빛돌 신입생 교육과정 1주차 - 16진 카운터 회로](https://blog.naver.com/homeless112/224164960120)

MCU 없이 IC 칩만으로 16진 카운터를 만능기판에 납땜해 구성했습니다. 처음 해 본 납땜이었습니다.

## 구성

| IC | 역할 |
| --- | --- |
| 555 타이머 | 일정한 주기의 클럭 펄스 생성 (가변저항으로 속도 조절) |
| JK 플립플롭 ×4 | J, K에 동시에 신호가 들어오면 출력이 반전되는 토글 동작으로 4비트 이진 카운트 |
| MUX | 디코더에 필요한 데이터 전달 |
| 디코더 | 카운트 값에 해당하는 핀으로 신호 출력 → LED 순차 점등 |

가변저항을 돌리면 555 타이머의 주기가 바뀌어 LED가 켜지는 속도가 달라집니다.

## 배운 점

- 납땜은 3시간 만에 끝났지만, 쇼트와 잘못된 연결을 찾아 고치는 데 **2일**이 걸렸습니다.
- 소프트웨어는 컴파일러가 틀린 곳을 알려주지만, 하드웨어는 오류의 원인이 눈에 보이지 않습니다. 회로를 단계별로 나눠 확인하는 습관이 필요하다는 걸 배웠습니다.
