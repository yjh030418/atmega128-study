# 5주차: UART 통신과 ADC

> 블로그: [빛돌 교육과정 5주차 - UART 통신과 ADC](https://blog.naver.com/homeless112/224177789198)

USART1로 PC(PuTTY)와 문자를 주고받고, ADC로 읽은 가변저항 값을 출력하거나 DC 모터 속도 제어에 썼습니다.

| 파일 | 내용 |
| --- | --- |
| `UART1.h` | USART1 초기화, 송신, 수신 함수 (1번 코드의 함수를 헤더로 분리) |
| `uart_echo.c` | 받은 글자를 그대로 돌려보내기 |
| `uart_echo_printf.c` | 에코 + 엔터를 치면 입력한 문장 전체 출력 (로컬 에코를 직접 구현) |
| `uart_group3.c` | 글자를 3개씩 모아서 한 줄로 출력 (`scanf`/`printf` 사용) |
| `adc_putty.c` | 가변저항 값(0~1023)을 1초마다 PuTTY에 출력 |
| `adc_motor_speed.c` | 가변저항으로 DC 모터 속도 제어 (ADC 10-bit → PWM 8-bit) |

## UART 설정

- 비동기식이라 양쪽 보율을 맞춰야 합니다. 9600 bps, 2배속 모드(`U2X1`)에서 `UBRR1 = 16 MHz / (8 × 9600) − 1 ≈ 207`입니다.
- 프레임: 8비트 데이터, 패리티 없음, 정지 비트 1개 (`UCSR1C |= 0x06`)
- `FDEV_SETUP_STREAM`으로 송수신 함수를 표준 입출력에 연결해서 `printf`, `scanf`를 썼습니다.

## ADC 설정

- 기준 전압: AVCC (`REFS0`), 채널 0 단일 입력
- 분주: 128분주 → 16 MHz / 128 = 125 kHz (ADC 권장 범위 50~200 kHz)
- 프리 러닝 모드(`ADFR`)로 계속 변환하고, `ADIF` 플래그를 기다렸다가 10비트 값을 읽습니다.
- 모터 제어에서는 ADC 값(0~1023)을 4로 나눠 PWM 듀티(0~255)로 바로 썼습니다.

## 마무리

5주간의 교육과정으로 GPIO부터 통신, 아날로그 입력까지 MCU의 기본 주변장치를 한 번씩 직접 다뤘습니다. 회로를 직접 꾸미고 레지스터를 데이터시트로 확인하며 짜다 보니 훨씬 깊이 이해할 수 있었습니다.
